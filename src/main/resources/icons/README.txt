Weather Icon Placeholders
=========================

This folder contains weather icon images for the app.
The following icons are used:
- clear.png - Clear sky
- cloudy.png - Cloudy/Partly cloudy
- rain.png - Rain/Drizzle
- storm.png - Thunderstorm

Due to the limitations of text-based setup, placeholder images are created.
For production use, replace these with actual weather icon images (100x100 PNG files).

You can find free weather icons from:
- https://www.flaticon.com/
- https://icons8.com/
- https://www.iconfinder.com/
