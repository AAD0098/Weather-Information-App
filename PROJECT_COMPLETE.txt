🚀 HOW TO USE

1. BUILD THE APPLICATION:
   ./build.sh

2. RUN THE APPLICATION:
   ./run.sh

3. USE THE APP:
   - Enter a city name (e.g., "London", "New York", "Tokyo")
   - Click "Fetch Weather" or press Enter
   - View temperature, humidity, wind speed, conditions, and forecast
   - Switch between Celsius/Fahrenheit using the unit selector
   - Check search history in the right panel
   - Background changes automatically based on time of day
